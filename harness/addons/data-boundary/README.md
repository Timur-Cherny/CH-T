# Дополнение data-boundary

Граница данных на выходе из сред: что агент может увидеть и вынести. Гейт `pre-bash`, анкета и их тесты — здесь;
ядро только подключает дополнение в своё место реестра (`src/gates/index.ts`) и держит общие парсеры (команды,
`psql`, SQL через libpg_query), которыми дополнение пользуется.

| Отбивает | Пропускает |
|---|---|
| строки бизнес-таблиц с прода (`psql`, прод-обёртки `mcp-pg-<канал>-prod`, `kubectl exec … psql`) | конфигурацию (`dataBoundary.configTables`) и агрегаты |
| выборку больше 1000 строк из нелокального контура, `pg_dump`/`pg_restore` прода | точечный разбор: идентификатор литералом, `LIMIT ≤ 50`, колонки явно, без `deniedColumns`, вывод не в файл (`dataBoundary.spotTables`) |
| печать секрета: `~/.pgpass`, `.npmrc`, ключи, `kubectl get secret -o yaml`, `printenv` с токенами | проверку наличия и размера секретного файла, его ключи без значений |

Без конфига дополнение уже полезно: секреты и выгрузки с прода закрыты, а любая строка прода считается бизнес-данными.
Конфиг площадки (`harness.config.json`, контракт — `harness/src/config.ts`):

```json
{ "dataBoundary": { "enabled": true, "configTables": ["countries", "app_settings"], "spotTables": ["orders"], "deniedColumns": ["user_id", "*_by_id"] } }
```

`enabled: false` выключает дополнение без перезапуска: каждый процесс хука читает конфиг. Выключатель на сессию —
`CLAUDE_SKIP_DATA_BOUNDARY=1` в окружении процесса клиента.

## Состав

| Файл | Что |
|---|---|
| `gate.ts` | гейт: модель команды (трубы, `sh -c`, `$(…)`, `kubectl exec --`), контур по хосту и маркерам, секреты |
| `sql.ts` | суждение по AST SQL: таблицы, колонки, агрегаты, `LIMIT`, точечный разбор |
| `answers.ts` | анкета с фиксированными ответами: `~/.claude/harness/bin/run addons/data-boundary/answers.ts --classify "<операция>"` |
| `test/` | обе стороны каждого правила и классы эквивалентности обёрток |

Слова, по которым шим будит Node для этого гейта, живут в общем префильтре ядра (`src/gates/prefilters.ts`): шим не
знает TypeScript, а лишний старт Node при выключенном дополнении стоит миллисекунды. Скилл к дополнению —
`presets/postgres-k8s/skills/data-boundaries`.

Новое дополнение — тот же порядок: код и тесты в `harness/addons/<имя>/`, импорт в `src/gates/index.ts` на место в
реестре, выключатель в конфиге, слова-триггеры в префильтре.
